# 套图风格与模板

改编自 buluslan / Buluu@新西楼的 ecom-image2 场景分类与 Campaign Style Lock，以及套图工作流的逐图分工。来源见 sources.md。

项目记录十项：视觉定位、图形色板、色彩处理、字体层级、背景语言、修图与光影原则、布局网格、图标/引线、商品呈现、不可漂移项。

固定：SKU、已确认配色外观、品牌色、字体、文案语气、图形样式、修图质感。图形色板不限制自然树木/天空/商品颜色，不用滤镜改产品色。

可变：地点、时间、天气、活动、机位、景别与构图。时间变化时同步调整高光、阴影、反射与环境色，不强行每张同光向同色温。不同场景依原规范在地点/时段/机位/活动中至少三项不同；同场对比款可明确例外。

## 版式与变更

具体布局库、归一化区域、信息预算和手机适配见 [layout-design.md](layout-design.md)。固定网格语言，不把相同版式强加每张图。

按职责选择通栏照片与底栏、文字轨、大主体加细节、非对称双栏、清单、无数值空间示意或真实规格。保护全景屋顶/脚座；近景只验可见范围。统一网格与字体，不要求每张同版式。

换风格建立新 campaign_version，复用身份、证据和受保护文案，保留原图。生成图可作有记录的风格参考，但不取代真实身份参考；记录累计漂移风险。

## 场景库

`python scripts/scenario_catalog.py list` → `show <id>`。39类保留上游分类与触发词，只输出可选视觉字段；示例功效、认证、规格、政策、模型已剔除。

模板仍需填充事实、具体镜头、逐字文案与输出。选择包装/拆解/多角度模板不授权编造隐藏结构或清单；无资料用已有视角或无数值示意。价格、视频、动图只在请求范围内制作。
