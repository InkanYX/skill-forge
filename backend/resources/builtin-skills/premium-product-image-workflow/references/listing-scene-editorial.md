# 商品套图：沉浸场景与证据编排

## SPC000327 V5 案例：将审美形容词落成摄影设计

依据用户提供的《SPC000327-沉浸式非对称V5-10张全套.zip》中的逐张原始提示词，以及可完整恢复的前三张图片。压缩包尾部缺失，第四张及之后不作为已验收图片；其余主题与修图仅有提示词记录。主图是独立的无文案产品任务；附图的成功方法不依赖统一白字金线。

选用沉浸画册时，把下面决策写入每张 design 和完整提示词，按实际产品调整：
- 参考角色：产品原件锁定身份、材质、连接和状态，不默认继承原件的机位与环境；认可成图才作为样式或编辑目标。新构图仍须传实际产品参考。
- 构图：写清产品偏左/偏右、占比或近似安全区域、完整轮廓保护、文字落点；非对称来自视觉权重而非倾斜相机或拉伸产品。主图与需要正视的证据图不强制偏轴。
- 镜头：说明高位/低位、斜向角度、景别和采用理由。案例用雨后低位斜视讲归家，再用高位斜视讲空间，不能全套只换背景却重复同一三分之四机位。
- 动线与光：写明前景框景、中景产品、远景任务环境；用真实道路、反射或建筑线条引导视线。光源方向、天气与产品反光一致，前景不得遮住验收所需结构。环境天气不证明防水、抗风等性能。
- 图文：照片先成立，去掉文字仍有明确主视觉；标题落自然负空间，条件紧随参数。拒绝默认顶部巨型标题、底部三图标、等大拼贴，但真实步骤/对照允许必要分区。
- 真实安装：落地面可用、接触与透视一致、人物车辆比例合理；道具不暗示包含物。产品颜色不可为配色方案改色。
- 逐字文案、禁止改变项与输出分别列明。画幅、原生尺寸、导出尺寸分开记录，不把此案例的1254×1254当通用上限。

可选的主题/镜头节奏示例：归家场景 → 高位尺寸 → 气候氛围 → 完整状态错落对照 → 材料近景 → 低位结构 → 操作框景 → 不同任务生活图 → 错落步骤。按当前卖点与图数取舍，不能复制案例规格、部件数或默认十图。雨景不能替代性能证据。

修图提示词还显示：先修局部，反复错误时扩大到能解释该功能的真实近景，例如把难辨的屋面安装小全景改为有资料支持的面板搭接近景。明确编辑目标、实际证据、允许改动区域和所有保留项；不得捏造工具、紧固件或截面，也不把历史修图指令当当前调用授权。


与 A+ 共用产品保真、完整提示词、真实参考编辑和针对性校正的方法，但套图是由独立可读的图片组成，不把 A+ 横幅或文字英雄图直接当作图库主图。

## 主图、附图分别设计

首张主图：完整呈现当前可售 SKU、清楚的形体与材质、合适机位和占比。无新增标题、卖点、文字、图标、徽章、边框、人物及非售卖道具，保留产品自带真实标识。背景按用户确认和实际槽位；明确选择非白底时不强制白底。人物、车辆和家具的空间展示放在允许此内容的附图，不能借“沉浸感”混入主图。

附图：一张回答一个主要购买问题，可配多个相关证据；从收益场景、结构功能、材质、尺寸/适配、操作状态、安装/收纳和包含物中选择。用户数量和当前事实优先，不固定七张/九张，不让尺寸或材质永远占同一图位。主图之后每张能独立理解；重复同卖点须增加决策信息，不只换背景。

每张 objective 写购买问题；notes 写证据来源、与相邻图的内容差异、重点验收项。design 明确主体占比与位置、景别、环境/证据层次、光线、文字阅读路径和变化理由。尺寸仅适用当前确认画幅，不将套图默认设为1464×600或4:3。

## 设计丰富不等于卡片多

- 场景收益图：完整环境有前中后景，主体可辨，活动和道具服务本图问题；文字放在自然负空间，不每页添加大色块和同款标题带。
- 结构功能图：大而清楚的整体或使用状态，辅以少量真实特写、准确引线；不以三枚图标和空泛标题替代结构证据。
- 材质图：用真实纹理、连接和工艺证据建立可信度，避免不明材质的装饰渲染；性能必须另有资料依据。
- 尺寸/适配图：确认测量端点、单位、条件；人物、车辆或家具只辅助尺度，不凭观感编造容量。
- 对照/步骤图：两个完整可辨状态或正确流程，保留必要操作条件；不把安装中间态误改成完成状态。
- 清单/收纳图：按当前产品资料核对件数与折叠状态，场景道具不暗示包含。

字体、图形语言和修图质感统一，机位、布局、证据方式有变化；不强制白字、金线、黄色背景或庭院场景。选择浅色字与细金线案例样式时，只用于允许文案的附图，且用户配色与可读性优先。场景数量取决于是否有不同购买问题，不用连续生活图挤掉关键证据。

## 参考、校正与小屏验收

先在图需中定义可确认的视觉方向；实际出图后，可选有代表性的附图作为已认可样式锚点。未取得认可成图前不得声称已有图像锚点。生成图只作样式/编辑目标，产品实拍和说明书仍决定几何、部件和包含物。纠错先由文本/视觉模型理解用户要求、检查实际底图及已有原件，再写精确编辑提示词，保留正确内容与上轮已接受修正。

建筑/车棚类可按实拍逐项检查顶面轮廓、面板拼接、框架数量、横梁/连接、支撑和落地关系；这些是检查项，不是默认具备的结构。与车辆同景时核对接触、透视和空间，不拉伸车棚来制造容纳效果。没有实际查看铁皮车棚旧案例原图时，不宣称已复现其具体布局或原提示词。

一次只看一张小体积JPEG，必要时查看原生局部。重点看主体完整、尺度/透视、连接与遮挡、文案数字和手机缩略图阅读；接触表只能检查整套节奏。套图按确认画幅检查约375宽阅读，不因手机预览自动改为A+手机画幅。另存原生、提示词、参考角色、实际尺寸、问题及修正版本；重试和计费处理遵守现有配置，不从历史聊天继承无限重试或静默修图兜底。
