# 文案质量与审查

改编自 ecommerce-visual-copywriting 的文案质量规则、输出契约与终态检查。用可核对依据作通过/待修复/不适用，不照搬无依据的80分线。

## 逐句检查

1. **购买理由**：除名称、必要规格/条件外，营销句是否说明“和我有什么关系”？结构说明只有承担证据或选择任务时才保留。
2. **信息增量**：副文是否补机制、条件或适配，而非重说标题？画面可见数量可用于规格，但不自动占一个核心卖点。
3. **证据边界**：材质全称、镀层/合成限定、型号、实验条件是否保留？看图观察不能扩成工艺、舒适、耐久或安全保证。
4. **数字有意义**：数字带单位、来源、对象和条件；有依据时用尺度或选择建议帮助理解，不编对照物容量、人数、阈值或时长。
5. **消费者语言**：少术语、残句和空泛品质词，朗读通顺。英文按目标市场自然重写，不照译中文四字口号，不擅加最高级。
6. **澄清归位**：件数和不含物放规格/可读注释；影响价格与到手内容的关键条件紧邻主张，不能藏小字。
7. **FAQ有效**：问题真实适用于本款、有证据可答、答案能帮助判断；答不了不编一个“视情况而定”。

## 长度与最终文字层

短图可从中文标题约6–12字、英文约3–7词、少量短副文开始，均为排版建议而非平台规则；实际画幅、语言、用户文案和必要声明优先。放不下就删冗余或拆图，不缩小关键条件。

集中列出消费者将看到的全部文字（包括标签、数字、条件、出处、不含声明）；缺证项不留“待确认/TBD/XXX”在图上。运行：

```powershell
python scripts/count-copy.py --language zh '按物品高度调整分层空间'
python scripts/count-copy.py --language en 'Adjustable shelf spacing'
python scripts/scan-final-copy.py 'Adjustable shelf spacing' 'Accessories not included'
```

count-copy 的中文计数含非空白标点、英文按空白分词，是内部排版约定。scan-final-copy 非零表示命中硬占位，soft项人工复核，合法括注不机械删除。这两个工具不能发现所有占位或判定主张真假；需人工审查。

## 五维交付检查

| 维度 | 通过条件 |
|---|---|
| 事实与适用边界 | 每条事实型主张能追溯，条件完整，SKU一致；当前政策结论另核官方来源 |
| 转化逻辑 | 主卖点回应具体买家任务，收益可解释，优先级有理由，非同义重复 |
| 视觉层级 | 第一落点明确，一图一主要职责，图文同一主题，移动端可读待成图核验 |
| 一致性 | 跨图身份、术语、数字、模特与Campaign对应；场景可变化 |
| 可执行性 | 完整制作卡、最终文字、独立提示词、参考角色和验收条件齐全 |

正式策划附简短检查结果及实际修订；只交本次请求层级。未满足的部分从最终稿移出，列明最小缺口，不把未验收的图或未验证的性能标为通过。

改稿报告给“位置/原句→问题及依据→替换稿→影响图号”。本地化另核语言、单位、货币、实际SKU电气/接口/尺码、真实政策和文化场景；不借翻译添加功能或承诺。
