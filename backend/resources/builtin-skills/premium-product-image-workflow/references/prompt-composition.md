# 将策划写成可调用提示词

保留 [prompt-writing-standard.md](prompt-writing-standard.md) 的十段式结构与原 [模板库](prompt-templates.md)。本模块补充编排与冲突检查，不另造一套平行格式。

## 制作卡到调用的四步

1. **选当前图的内容。** 从矩阵提取购买问题、point_id及claim_id支持范围；内部ID保存在制作卡，不作为消费者文字。照片推测按 [推测模块](photo-inferred-selling-points.md) 分层；概念草案标明用途，成品只用可支持的表达。
2. **展开视觉计划。** 将布局ID展开成实际区域、机位、景别、主体占比与细节内容；只载入本图实际使用的参考。参考多图还是单图依现有接口与项目配置，不擅自更换网关或模型。
3. **写入十段模板。** 各段落实具体决定，Exact copy仅列完整最终字符串；实际调用删除空字段和未填变量。相同身份/风格在每图重复必要约束，不写“同上一张”。
4. **核对并保存实际文本。** 检查图需→Prompt无遗漏，Prompt→图需无新增主张；运行对应route的原lint工具，记录实际上传文件、顺序、提示词版本和输出参数。模型生成后仍需图像与逐字验收。

## 每段怎样具体化

| 段落 | 应写的内容 | 避免的空话或越界 |
|---|---|---|
| Task and selling objective | 一个买家问题，证据如何支持它 | 同时宣传全部候选卖点 |
| Reference roles | 实际参考编号、身份/风格/排版职责 | 指定未上传的参考；复制竞品身份 |
| Product identity lock | 易漂移部件、总数、连接、颜色、比例 | 只写same product；强迫所有部件同时可见 |
| Scene and camera | 地点/活动、机位、景别、道具及物理尺度 | 不可能的视角、隐藏结构补全 |
| Composition and hierarchy | 归一化区域、占比定义、阅读顺序、空隙 | 只写高级排版；多区占比合计不可能 |
| Art direction and physical realism | 实际Campaign、材质外观、光源与环境互动 | 用抽象形容词或8K字样替代设计 |
| Exact copy | 带引号的标题/副文/标签/声明，大小写与断行 | let the model write persuasive copy、TBD |
| Typography and graphic layout | 标题与正文层级、位置、行数、对比、引线对应 | 同时要求居中和左对齐、文字覆盖证据 |
| Strict exclusions | 与本SKU/本任务相关的少量禁止项 | 无差别复制长禁词表，意外禁止所需内容 |
| Output | 完整成品、比例、实际支持的调用尺寸与交付目标 | 将Prompt中的像素文字当成实际原生尺寸保证 |

## 路由与长度

- 新附图/A+：完整十段，文案与布局一体生成。用户要底图时明确采用底图任务，不把底图冒充成品。
- 主图：精简身份、全貌、背景、光影和禁止新增文字/道具；不要机械加Exact copy。
- 局部编辑：首句 `Edit only ...` 指定唯一目标，明确保护项与输出；仅对相关区域提出改变，不能一面锁定全图一面要求重构。
- 换风格/换场景：列受保护事实与文字、允许变化字段及其物理连带变化。时间变化时允许阴影/反射合理更新，不能同时锁死所有光影。

Prompt不按100–150词机械截断，也不为长而堆砌。先保证SKU、任务、证据、区域、文案和限制完整；过长时删除重复形容词及无关卖点，保留易错结构与逐字文案。正文按原规范英文，图内文字保留目标市场语言。

## 调用前冲突清单

- “完整商品”与“主体紧裁”、新视角与“保留原机位”、背景改变与“背景不变”是否同时存在？按本次请求消解，不用“必须全部满足”掩盖冲突。
- 文字区和商品区是否实际重叠关键结构？标题行数与字量是否相容？将区域重新分配，不靠缩小商品变成小摆件。
- 是否误把材料候选、机制猜测、参考样图参数写入确定宣称？回到证据状态处理。
- 是否把风格参考的形状、Logo、配件和文案迁给本SKU？参考只承担指定职责。
- 尺寸、画幅和模块数量是否一致？原生尺寸、导出目标与平台槽位是否分别记录？

修复错误后用同route再lint；无错误不代表排版或结构已通过。成图缺字/错位按原质量闸门处理，局部返工保护正确区域并遵循已有重试上限。
