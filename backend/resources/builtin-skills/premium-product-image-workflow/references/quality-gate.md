# 交付质量闸门

在声明图片可交付前，逐张执行以下检查。任何 P0 或 P1 未解决时，不得交付为最终图。

## 产品身份

- [ ] 是否为相同可售 SKU，而不是外观相似的商品？
- [ ] 关键部件数量、位置、连接关系、颜色和材料是否正确？
- [ ] 是否出现新增、缺失、重复、替换或简化的部件？
- [ ] 是否保留正确纹理、接缝、五金、褶皱和配件？
- [ ] 是否存在拉伸、压扁、弯曲、扭曲、错误透视或不自然裁切？
- [ ] 关键结构是否被景深、人物、道具或前景遮挡？

## 光影与真实感

- [ ] 光源方向、高光、阴影、反射和环境色是否一致？
- [ ] 是否存在自然、合理的接地阴影？
- [ ] 布料、金属、木材、塑料、玻璃、皮革等材质是否可信？
- [ ] 人物、家具、车辆、植物与商品的尺度是否合理？
- [ ] 天气、地面、天空、水面和商品表面状态是否一致？

## 商业表达与平台合规

- [ ] 商品是否为清晰视觉中心？
- [ ] 是否围绕一个清晰主要购买主题组织足够内容，相关子卖点由准确细节 / 状态 / 示意支撑，而非限制为单个零件？
- [ ] 缩略图、图标、结构补绘是否各有信息增量；补绘有可追溯依据、未知结构未冒充SKU事实；静态动势效果未冒充实际动画或测试？
- [ ] 留白、层级、对齐和移动端可读性是否合格？
- [ ] 桌面转手机是否已独立重排，而非整幅缩小、中心裁切、拉伸或补边？在设计基准宽度及实际手机显示宽度下，场景/操作内容、关键尺寸和限定是否仍可辨认？检查方法见 [手机端重排流程](mobile-adaptation.md)。
- [ ] 是否分别核验手机画幅基准、实测原生像素与导出像素，未把600×450误当高清上限，也未把插值放大描述为新增细节？
- [ ] 主图是否符合目标平台当期规则，并无文字、徽章、图标、尺寸、Logo、水印、边框、人物、道具或非售卖物？
- [ ] 是否不存在误导性道具、夸张效果或暗示未包含配件？

## 文案、数据与合规

- [ ] 标题、拼写、标点、大小写和断行是否正确？
- [ ] 数字、单位、尺寸、型号、材质、认证与性能是否均有用户确认依据？
- [ ] 是否无乱码、漏字、错位或难以阅读的文字？
- [ ] 是否无绝对化、夸大、无法证明或不合规的宣传？
- [ ] 商业上线图是否已按适用要求完成 AIGC 标识和元数据处理？

## 缺陷分级

| 级别 | 判定 | 行动 |
|---|---|---|
| P0 | SKU 错、关键部件增减、比例严重变形、虚构参数 / 主张、主图违规 | 强制返工，不得交付 |
| P1 | 材质错误、光影矛盾、文字错漏、卖点无证据、关键结构遮挡 | 返工后复检 |
| P2 | 内容单薄、无意义重复、辅助图过小不可读、留白不足、版式不齐、场景品质不足、阴影或色调影响高级感 | 优先优化，高端商品建议返工 |
| P3 | 小范围色调、装饰或轻微构图偏差 | 记录，按用户标准优化 |
