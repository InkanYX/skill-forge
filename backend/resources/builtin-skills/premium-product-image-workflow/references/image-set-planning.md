# 套图规划与视觉一致性

## 1. 先建立风格锚点

在生成第一张附图前定义并贯穿整套：

```text
Visual style anchor:
- Keep the same product SKU, color, structure, materials and proportions as the reference.
- Match the established visual identity: [minimal / premium / warm outdoor lifestyle / modern industrial].
- Use the same color palette: [primary], [secondary], [text color].
- Keep a consistent brand retouching language; adapt light direction, temperature and shadows coherently to each approved scene and time of day.
- Use consistent typography, icon style, margins, alignment and information-card styling.
- Maintain the same photorealistic quality and retouching level across the complete image set.
```

将第一张通过验收的图作为母版，后续图继承产品、色彩、光影和版式语言，但不可重复同一角度、同一卖点或同一信息任务。

首个风格锚点可选择最能代表品牌的附图，不必是图库第一张。继承的是设计语言；同卖点可在利益图、证据图或选择图再次出现，但须增加不同决策信息，不能重复同一句话与同一个证据。

整合版以 `campaign-style.md` 区分固定品牌语言与可变场景；光影一致指每张图内部物理一致和跨图修图质感一致，不强制晨间、黄昏与室内具有相同光向/色温。生成母版不能取代真实 SKU 身份参考。

## 2. 常规 6–8 张套图

按“看见 → 理解 → 相信 → 行动”安排：

1. 主图：商品识别、白底合规。
2. 核心卖点：最强且已证实的购买理由。
3. 结构 / 功能：差异化部件和使用逻辑。
4. 材质 / 工艺：纹理、接缝、五金、厚度或真实细节。
5. 尺寸 / 规格：仅已确认参数，降低退货风险。
6. 场景图：目标人群、用途、氛围和尺度关系。
7. 安装 / 收纳 / 兼容：降低理解成本。
8. 包装清单 / 服务：明确包含物和购买预期。

## 3. Template 1：九图套组

用户提出“模板1”或“Template 1”时，按以下职责设计 9 张同画幅图：

| 图号 | 类型 | 唯一任务 |
|---|---|---|
| 1 | 主图 | 完整产品、第一眼识别、无文字和干扰元素 |
| 2 | 场景图 | 合理天气 / 季节 / 环境中的产品美感与适配性 |
| 3 | 场景图 | 另一使用地点、目标人群或生活方式 |
| 4 | 功能图 | 最影响购买决策的已验证卖点 |
| 5 | 细节图 | 结构、材质、五金、接口、接缝或关键部件证据 |
| 6 | 功能图 | 第二功能、操作、开合、调节或收纳状态 |
| 7 | 细节图 | 补充功能、耐用性依据、已含配件或差异点 |
| 8 | 空间图 | 容纳能力、实际活动空间和尺度关系 |
| 9 | 规格图 | 已确认的尺寸、结构、兼容或包装信息 |

## 4. 分工禁区

- 不用“场景 + 大标题”替代功能证据。
- 不让两张图重复同一决策信息；同卖点从不同证据或选择角度展开时说明增量。为可比性需要同机位的操作/型号对照可保留，其他场景避免机械重复。
- 不为统一而牺牲单张图片的职责清晰度。
- 不在主图中塞卖点文案、图标、尺寸、徽章或非售卖物。
- 不编造尺寸表、认证标识和性能。成品直接生成文字与版式，已确认文字和数据必须逐项核对；减少冗余文字，不以微小字号塞满画面。

## 5. 从图序到制作卡

图序表只用于检查整套叙事，不可代替逐图图需。每张最终图均须使用 `listing-image-requirements.md` 的制作卡字段，并单独产出：

- 纯英文完整成品提示词，包含场景、风格、构图、卖点证据、逐字文案和版式；
- 与提示词一致的成品版式核对说明，包含标题、副标题、事实来源、字体、位置、颜色、行数与安全边距；
- 场景与机位差异说明。对两张以上的场景图，地点、时段、机位、活动至少三项不同；
- SKU 事实来源和 P0/P1 验收点。

将竞品研究映射为“购买问题、视觉证据、信息密度与阅读顺序”，不得映射为可直接复用的画面、文案、图标或布局。

## 6. 按购买障碍调整图序

上述6–8图是起点；用户指定图数、模板和顺序优先。未指定时先列买家疑问，再排图，不能为了填满槽位编造服务、材料或性能。

| 商品主要决策障碍 | 建议的信息推进（按需要删减） |
|---|---|
| 品类/外观不易识别 | 商品身份→整体/用途→核心利益→细节证据→选择 |
| 尺寸/兼容最容易买错 | 商品身份→尺寸/适配→核心利益→操作/机制→场景 |
| 功能机制复杂 | 商品身份→结果价值→已核实机制/操作→证据→规格 |
| 审美与场景驱动 | 商品身份→主场景/搭配价值→设计细节→另一有效场景→规格 |
| 套装/数量容易误解 | 商品身份与真实件数→到手清单/选项→利益→场景→规格 |

排序依据标明来自用户、已有研究还是策划假设；没有点击/转化数据不称为已验证最佳顺序。关键选择信息可提前，不固定把尺寸放第5张。证据不足的模块改用可支持主题，用户要求固定数量但信息不足时说明缺口，不用重复图冒充新卖点。

## 7. A+和详情页的模块节奏

- Listing承担独立可读的购买问题；A+/详情页可连续叙事，但单模块仍需清楚。不要把图库换尺寸后原样重复当完整A+策划。
- A+从品牌/产品身份切入，再展开主利益、细节/机制、生活场景、选择或规格；有真实系列数据时才做比较表，有品牌证据时才讲相应故事。按实际槽位和图数合并/拆分。
- 详情长图先承接首屏承诺，再给核心理由和证据，随后场景、选择/规格、真实FAQ/服务。图中引用上一模块的信息时，必要条件仍要在本模块附近清楚可读。
- 宽幅模块优先一幅横向主体加一组短信息；方形卡承担细节；长图按屏分段，不用一幅全景同时塞完所有内容。具体排版见 [layout-design.md](layout-design.md)。

## 8. 整套节奏与交付表

整体/局部、环境/信息、疏/密按内容交替，避免连续多张相同大主体+三图标；不为变化强加无用图型。保持字体、边距与图形语言，允许单张因职责不同改变构图。联屏检查视觉锚点是否稳定、机位是否必要、同义卖点是否重复、关键疑问是否缺失。

使用 [图序排版矩阵](../assets/image-sequence-layout-matrix.md)，将图号、决策阶段、point_id/claim_id、信息增量、布局ID、参考角色、文字量和验收点汇总。矩阵不替代完整制作卡；局部修改不强制重排整套。
