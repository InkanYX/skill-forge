# 参考图片治理：自有成图、产品图与竞品图库

同一项目中的参考图片必须先按来源与权限分组。它们不能因为“看起来有用”就共同作为图像模型输入。

| 参考组 | 允许用途 | 可进入生图/编辑输入 | 不可迁移内容 |
|---|---|---|---|
| 产品身份参考 | 锁定 SKU 几何、部件数量、颜色、材料外观、连接关系与自然比例 | 可以；先取得用户对第三方上传的明确授权 | 未能从图片确认的尺寸、性能、材料牌号、包装与服务 |
| 自有已完成 Listing 图 | 提取品牌视觉系统、字体组合、色板、排版、信息密度、免责声明位置；可作为后续同 SKU 的版式/风格参考 | 仅当用户确认拥有使用权且明确授权上传时可以；可作为成品提示词的风格/版式参考，明确禁止迁移参考中的产品几何或未经确认文案 | 图片中未经确认的性能、材料、尺寸、认证、包装或服务文案；不把“已在图片上出现”当作事实证明 |
| 自有已批准文案/规格图 | 提供已确认的逐字文案、数字、单位、型号或免责声明 | 已确认文案和数字直接写入成品提示词，并在生成后逐字核对 | 不完整、过期或没有来源的字段 |
| 公开竞品图库 | 仅用于内部研究：图序、购买问题、证据方式、机位类型、留白、信息密度、场景角色和视觉惯例 | 默认不可以。不得将竞品图上传至图像模型、混入拼贴、作为风格迁移源或上架素材 | 竞品图片、文字、Logo、图标、产品结构、尺寸、性能、认证、独有道具组合、场景布局 |

## 1. 先建立参考登记表

每张参考图必须登记来源、权利状态、唯一角色、可用信息、不可用信息与是否可上传。模板如下：

| 编号 | 来源 / 文件 | 权利状态 | 唯一角色 | 可提取内容 | 事实状态 | 可上传到图像服务 |
|---|---|---|---|---|---|---|
| R1 |  | 用户自有 / 公开竞品 / 未确认 | 产品身份 / 品牌视觉 / 已批准文案 / 竞品研究 |  | 已确认 / 待复核 / 禁止推断 | 是（已授权）/ 否 |

## 2. 用自有成图建立品牌视觉锚点

从用户提供的自有成图提炼以下**风格变量**，写入 `00_brief` 与 `01_plan/00_visual-system.md`：

- 品牌标识与其安全区；只在用户确认商标使用权后进入最终排版。
- 标题/正文的字体类别、字重、大小写、行距、信息层级和最大行数。
- 色板、背景处理、信息卡、圆角、描边、图标线宽、分隔线、免责声明位置与留白策略。
- 场景调色、光照时间、对比度、景深、主体占比和局部模块的数量。
- 用户已经批准的叙事方式，例如“完整使用场景 → 局部结构证据 → 规范概览”。

不得照抄任意单张旧图。新图仍需有独立购买问题、场景/机位差异和原创构图。

## 3. 处理已有图片中的文案

把已有图上的每条文字分为：

1. **已确认可复用**：用户明确说明它是当前 SKU 的已批准、真实文案，或有规格来源。可进入布局文件，保持精确拼写。
2. **待复核候选**：已存在于用户图片，但未有资料确认。可作为要核对的候选；不得进入新图、提示词或最终排版。
3. **禁止迁移**：竞品文字、错误文字、未经支持的性能/认证/比较结论。

每张附图的版式核对文件必须记录使用了哪一类。只有已确认可复用文字进入成品提示词，随画面直接生成并逐字核对；待复核候选和禁止迁移文字不进入生成。

## 4. 竞品到自有的安全转换

将竞品观察转换为以下五个可用维度：`购买问题`、`视觉证据`、`镜头/商品占比`、`信息密度`、`场景角色`。再由自有 SKU A 级事实与品牌视觉锚点决定新图。

禁止把竞品图片当作“风格参考图”上传到模型。即便用户希望“参考竞品”，也只能在项目文档内写出抽象制作决策，例如“使用一个大结构近景证明连接关系”，不能指定复制其画面或模块布局。

## 5. 最终审计

每张最终图需要能追溯：产品身份来自哪张自有产品图、品牌版式来自哪些自有成图、文本来自哪个已确认来源、竞品洞察仅如何影响购买问题或证据方法。来源与用途不一致时按 P1 处理。
