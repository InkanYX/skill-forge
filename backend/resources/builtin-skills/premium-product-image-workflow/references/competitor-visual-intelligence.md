# 竞品视觉情报报告规范

本报告将已下载的 Amazon 公开商品图库转为原创 Listing 图片决策依据。它只分析图库中实际下载的图像和 `manifest.csv` 中的来源记录，不基于首屏截图、A+ 横幅、评论图或类目常识补全。

## 报告状态

报告首页必须标记以下之一：

- **已完成**：至少一个候选的商品图库被正常下载，并完成来源清单、逐图标注和跨竞品总结。
- **部分完成**：部分候选有图库；明确哪些 ASIN / 图序缺失及原因。
- **已跳过**：用户明确不要研究，或未提供站点、公开类目页和关键词。
- **被阻断**：出现 CAPTCHA、拒绝访问、限流、登录墙、异常跳转或图片访问控制；写明停止时间和已完成范围。

不能用“已下载竞品链接”代替图片研究完成状态。

## 逐图标注规则

每一张下载图均填写一行，至少包含：

| 字段 | 写法 |
|---|---|
| 来源 | ASIN、公开来源页、图库图序、文件路径和采集时间 |
| 图像类型 | 主图、场景、核心卖点、结构、材质、尺寸 / 清单、视频海报等 |
| 购买问题 | 该图试图回答的买家问题，而非竞品标题或文案复述 |
| 可见证据 | 完整商品、局部特写、使用状态、环境尺度、参数示意等可观察元素 |
| 构图 | 机位、景别、商品占比、留白、详情模块数量 |
| 风格 | 背景、色板、光源、反差、后期等级、文字密度和图标使用 |
| 可抽象方法 | 可迁移的图序或证据方法，例如“完整商品 + 大细节特写” |
| 不可迁移内容 | 竞品图像、文字、Logo、产品几何、独特道具组合、认证 / 性能结论 |

“防水”“抗风”“隔热”等不能因为竞品图展示或标注就写为本 SKU 卖点；这些只能进入“待确认资料”清单。

## 跨竞品总结

对所有标注行做汇总，而不是挑一张最好看的图：

1. **图序覆盖**：哪些购买问题被大多数竞品在第几张图回答，哪些问题未被充分覆盖。
2. **视觉惯例**：主图背景、商品占比、常用机位、场景复杂度、文字密度、色彩和光线规律。
3. **证据方式**：竞品如何让买家理解结构、材料、尺寸、空间或使用方式；只总结方法。
4. **同质化与机会**：只在本 SKU 有 A 级证据时提出差异化机会；否则列为 B 级资料需求或 C 级禁止项。

## 映射到自有 Listing

最终必须将机会映射到自有图序。每一行都要有本 SKU 证据等级和禁止项：

| 市场机会 | 本 SKU 可用证据 | 等级 | 自有图号 | 原创表现方法 | 不可迁移 / 禁止项 |
|---|---|---|---|---|---|
|  |  | A / B / C |  |  |  |

只有 A 级可进入成品提示词；B 级需先确认；C 级不得进入图片、文字或设计暗示。
