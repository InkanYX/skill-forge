# 内容充实与辅助视图

用于用户认为内容单薄、希望增加卖点密度、缩略图、图标、结构图或效果示意时。用户偏好信息充实的附图；不将此偏好套到无字主图或强制每张塞满模块。

## 主题与内容量

一个主要购买主题可以包含多个相关收益和证据。策划时先定“买家看完能判断什么”，再组合有独立信息的子卖点；内容丰富的附图可从2–4个相关支撑模块起步，根据可读性增减，不按固定数量凑点。

- 将包边、单颗螺丝等弱细节并入“接触部位处理”“雨水防护”“连接体系”等有意义的主题，除非其独立价值足以撑起一张。
- 大场景承担使用感和身份识别；缩略图承担真实部位、另一状态或不同用途；图标用于快速定位信息。每个模块写明新增事实、收益或选择信息。
- 相同零件可在不同图出现，但须改变信息任务，例如一张解释围布拆装，另一张解释连接路径；重复一句方便/牢固不算新增。
- 不靠换词、复制图标、重复同一角度或增加无关小图显得充实。需要的图数超过可支持内容时先重组并说明，不凭空制造性能填满图位。

## 卖点扩展

主动重看原始照片里的形状、纹理、立柱分布、连接、接缝、孔眼、卷帘和使用状态。区分用户确认、照片可见、照片推测、场景建议四类。

照片推测按 photo-inferred-selling-points.md 记录依据、置信度、替代解释、当前可用表达与待证项。可见的方管轮廓可以写“方管框架”，不能自动升级为“加厚钢材”“粉末喷涂防锈”“抗撕裂围布”。用户允许创意补全，不会自动给出未知参数。

## 辅助图与补绘

| 类型 | 可执行范围 | 验收重点 |
|---|---|---|
| 多角度/局部重构 | 根据原图已支持的外形重拍、补绘、重新布光及换背景，不必等一张完全相同机位的实拍 | 数量、位置、连接、颜色和轮廓可追溯；生成候选再验收 |
| 框架透视/去围布视图 | 可重建已支持的立柱、梁、弧形顶撑与斜撑；示意用途写清楚 | 不能补造看不见的横梁、地脚、加强件、截面壁厚或孔位；不把效果图当作测量证据 |
| 未知结构概念 | 用户要求时可做设计概念；项目中单独标记“结构概念/待核对” | 不进入真实SKU最终图库；消费者可见的精确技术示意仍须有依据，单加示意标签不能使错误结构成立 |
| 图标与动势效果 | 雨滴、风向、拆装箭头、局部高亮、状态切换等帮助理解的静态图形 | 不伪造测试、认证、安全等级、流量、承载数值或不存在的动作 |
| 真实动画 | 仅在用户要求且实际展示槽位支持时制作GIF/视频等独立资产 | JPG/PNG里的箭头、高光、水滴是静态效果，不能描述为实际可播放动画 |

生成微距可补可见形态的表达，不能通过AI补图发明材料成分、工艺、隐藏结构或性能证据。不能因为没有完全一致的原始局部照就停止有依据的画面设计。

## 制作卡与质量门

在制作卡补：`主要主题 → 相关point_ids → 主画面 → 支撑模块/每项信息增量 → 图标/静态效果/动画格式 → 补绘依据与未知范围 → 手机阅读顺序`。

通常主画面、2–4项支撑模块、短标题及必要条件即可形成丰富内容；按实际密度调整。缩到目标展示宽度时仍应看懂主收益和关键证据。不能用密集小字、极小缩略图、装饰抢焦点来满足丰富度。

验收增加两项：内容是否足以独立支撑本图；每个辅助模块是否准确且提供新信息。内容单薄或无意义重复记为P2；补造SKU结构、错误参数仍按原P0/P1处理。
