# 桌面成图转手机端：独立重排与高清交付

用于已有桌面A+、商品场景图或卖点图的手机端版本。继承原SKU、事实、已确认修正与Campaign；按本次请求适配，不顺带重做其他版本或增加新宣称。

## 画幅、像素与显示尺寸

把画幅/排版基准、文件像素、手机实际显示宽度分开。

- Premium A+常用600×450作为4:3画幅与排版基准，不把它当一律必须输出的精确像素或清晰度上限。用户仅说“手机端600×450”而未强调精确上传像素时，可沿用4:3并交付更高清文件，明确告知实际尺寸。用户或已核实后台要求精确600×450时，另外导出该规格。
- 无精确像素限制且原生细节足够时，优先交付1200×900；需要轻量文件可用900×675。保留更高分辨率原生图。这是制作偏好，不是平台保证接收的规则；实际槽位、文件大小限制与用户选择优先。
- 高清以真实原生细节为前提，不把600×450插值放大称作高清重制。像素增加后字体和内容仍按手机显示大小设计，不趁机堆字或缩小必要条件。
- 其他目标画幅按实际比例独立适配，不强制所有手机图都为4:3。生成参数用接口实际支持的尺寸；提示词里的目标像素不等于实测输出。

## 来源与逐图制作卡

从最新交付清单确认范围和采用版本，按原图号一一对应；套图中已新增的步骤/补充图也纳入用户所说的“整套”。不重读全部历史或误用被否定旧版。

每张记：主要购买问题、必须展示的产品部件与场景/活动、保留文案及数字/限定、原版本修正、目标比例、布局区块、参考职责和像素策略。桌面成图作主题/风格/场景与受保护内容参考；实拍和必要说明书页作真实结构证据，优先于生成图。精简信息只删冗余或按授权改写；不删除尺寸净空条件、配件不包含、安装人数等影响理解的限定。

## 按图型重排

| 图型 | 手机布局起点 | 保留重点 |
|---|---|---|
| 首屏/生活场景 | 上方短标题，下方大场景；调整机位和道具，保留前中后景 | 完整产品、使用活动、可信尺度、氛围和排除声明 |
| 尺寸 | 主体居中，尺寸线沿真实轮廓；标题和条件分置上下 | 数字/单位、测量对象和端点、名义尺寸与净空区别 |
| 结构/材质 | 主体加下方或侧方足够大的近景；按内容选2–3处，不强制三格 | 连接几何、真实纹理、标签/引线对应；细节不变邮票 |
| 状态/使用对照 | 两幅大图并排或上下，按需要保留操作近景 | 同一SKU，各状态一致完整，无闭门叠卷门等矛盾 |
| 单一操作近景 | 放大操作与连接，信息放安静区域，警示就近 | 手/工具与硬件关系、操作条件，不恢复用户已删缩略图 |
| 固定方式比较 | 按表面分区，条件紧邻对应实图 | 包含/不包含、适用表面、脚板与锚固关系 |
| 多用途轮播 | 每用途独立重构完整场景，统一标题语言 | 用途/活动、产品形态和场景层次，不为塞字抹掉场景 |
| 简易安装步骤 | 四步横列可改2×2，也可按画幅上下组织 | 真实顺序、状态变化、编号、完整轮廓及必要提示 |

按商品和内容分配区域，不套固定模板。完整外观图保持轮廓和接地部位，近景任务保护相关部件。不得用居中裁切、整幅缩小加大白边、拉伸或把桌面图塞进4:3背景替代重排。尽可能保留美观、丰富、有沉浸感的场景；留出清晰信息区即可，不用大面积空白挤掉主题。

## 提示词与执行

使用 [十段式规范](prompt-writing-standard.md)，保存实际调用文本并lint。明确允许变化的机位、场景布局、图文区块和字体，单独锁定SKU、文案/数字/条件、已通过修正与风格。清理桌面版旧占比、文字轨、尺寸、裁切和位置指令，避免与新布局冲突。

输入按顺序标明桌面编辑目标、严格身份实拍、必要的局部/说明书证据。沿用现有授权和出图配置，不因尺寸变化切换接收方、模型或放宽保真；不把单个项目的同意写成永久上传授权。先验代表作，再做其余图；只返工失败或缺陷图，遵守现有重试上限。

Output段写明新目标比例、完整成品和所有已排好的图内文案，实测原生/交付尺寸；不能交付无字底图或待后期排版图。要求高清仍需核对实际输出，不能用提示词像素冒充生成结果。

## 逐图验收

- 对照桌面最新正确版本和真实来源，核对SKU、部件、已修正处及场景/活动；不能只验证宽高。
- 在原生细节预览、600宽设计基准及约360–390宽实际手机预览检查，其他基准按实际模块替换。高像素图也要缩到实际显示大小验读，不能以电脑放大时能看见代替手机可读。
- 标题一般1–2行，主副文/标签/必要条件层级清晰、不压关键结构。字号可从600宽基准标题约28–32、正文18–20、标签16–18像素起步；限定文字依实际验读结果分配空间，不以固定小字号硬塞。高像素制作按比例放大字体，实际显示字号不变。
- 逐字核对标题、副文、标签、数字单位、条件和排除声明；检查引线、尺寸线和步骤编号。总览只验一致性，不替代逐图细节检查。受本地图片大小/上下文限制时，用有界JPEG或相关局部验图，原生文件不动。
- 关键结构变形、条件遗漏或文字不可读按现有P0/P1闸门返工，不靠提高像素掩盖。

## 导出、状态与打包

仅对新构图、已验收且近似同比例的图做等比高清导出，通常1200×900即可，保留原生版本。有明确要求时另给600×450兼容副本，勿覆盖高清版。比例明显不符返回构图阶段；仅明确审阅过且不损失内容的微小背景边缘调整可作为导出处理。

现有导出器支持自定义像素，不需把预设换成另一个硬上限：

```bash
python scripts/export_product_images.py resize mobile-native.png --size 1200x900 --out mobile-1200x900.png
```

`--module premium-mobile`仍表示精确600×450兼容导出，不负责将桌面版变成手机布局。不要给桌面横幅用`--fit contain`后把补边结果当手机成品。

桌面与手机分目录/清单，沿用图号，记录 `based_on`、`layout_reference`、`aspect_ratio`、`native_pixels`、`export_pixels`、实际提示词/参考哈希、布局变化、验读宽度及结论。生成、验收、导出分别记录。完整包包含所有采用手机成品、原生图、提示词、预览和清单，核对图号完整、实际尺寸/比例、文件哈希及ZIP完整性。手机图只有实际生成、检查和导出后才算完成。
