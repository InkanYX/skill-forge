# 平台、品类与本地化适配

这是对两个来源技能的平台与品类方法的改编摘要，不是现行平台政策或法律结论。只读取当前任务对应行；涉及具体尺寸、禁限词、资格、认证和审核条款时核验该市场官方来源，记录文档和日期。源技能的历史访问结果不继承为本次核验。

## 平台信息组织

| 平台/位置 | 策划重点 |
|---|---|
| Amazon Listing | 白底身份与真实件数→核心利益→细节/证据→场景→尺寸/适配；主图与附图区分 |
| Amazon A+/Brand Story | 用模块展开价值、机制、场景与选择；复用已确认卖点，避免整页重复图库口号；核对资格与模块槽位 |
| Shopify/DTC | 首屏单一价值→理由与证据→选项→真实FAQ/政策；长解释可留网页正文，不全烧进图片 |
| 淘宝/天猫 | 搜索识别→利益→证据→选择；主图/详情/SKU件数与活动口径一致 |
| 京东 | 参数、条件、兼容、安装空间与真实服务，参数翻译成选择价值 |
| 拼多多/Temu | 到手内容、数量与价格条件清楚，不能低配价格配高配画面或虚构折扣 |
| 抖音小店 | 商品卡与实际内容事实一致，一图一利益、真实使用过程；不互套TikTok规则 |
| TikTok Shop | 先定国家/站点，再本地化语言、规格、场景和购买条件 |
| 小红书 | 区分商品图和笔记封面，真实使用语境；不伪造亲测、素人评价 |
| 视频号/微信小店 | 区分内容封面、商品卡和详情，图片与挂载SKU、价格及政策一致 |
| Shopee/Lazada | 两平台各按站点核实；优先语言、件数、尺寸和适配的移动端理解 |

平台不决定固定字体/色板。语言可重写，材料、净含量、电压、功效与认证适用范围不能为本地化而改变。单位换算保留原值和精度依据，不能将未确认尺码换成当地通用码。

## 品类提炼重点与常见越界

| 品类 | 优先寻找的购买理由 | 需要额外依据的内容 |
|---|---|---|
| 家居/收纳 | 空间与尺寸选择、已确认调节方式、到手组合、搭配 | 承重、节省百分比、任意物品适配 |
| 户外/凉亭 | 真实结构、布局、用途、配件操作与规格选择 | 抗风、防水、防晒等级、降温、容纳人数与安装时长 |
| 服装/鞋包 | 可见设计与版型、已确认面料、尺寸选择、穿搭场景 | 舒适、透气、显瘦量化、防水耐磨；不凭照片猜纤维 |
| 饰品 | 真实造型、材料规范全称、镀层限定、尺寸与搭配 | 不褪色、不过敏、佩戴位置/适配阈值；不能由照片判工艺 |
| 工具/3C/家电 | 参数对应任务、接口兼容、操作与选择边界 | 节能、噪声、寿命、提速比例与安全认证 |
| 食品/美妆/健康/母婴 | 真实配料/标签、规格、使用方式与对应资质 | 疾病/健康功效、保证效果、安全保证与特殊人群适用 |

## 宣称与画面联审

核对实际市场的广告真实性、比较、数据引证、健康、儿童、促销与认证范围。中国市场可从国家法律法规数据库、市场监管总局、国家药监局与平台官方入口定位；美国市场按问题定位FTC/FDA及平台文件；其他市场不移植中美结论。

同样审查隐含主张：盾牌图标可能暗示防护，雨雪场景可能暗示耐候，前后图可能暗示实测效果。不能只删文字而保留同等误导画面。需要法定批准或正式证明而材料不足时，完成其他可支持模块，把该主张列为阻断；不把普通策划自审当法定审核。

价格核对币种、SKU、数量、单位/组合总价、门槛、人群、活动期、运费；服务采用真实店铺政策；证书核对持有人、对象、范围与有效期。不用“最好、唯一、第一”等措辞替代证据，不编造评价、销量、认证、专利、原价或倒计时。
