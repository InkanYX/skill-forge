# Amazon Listing 图需与最终排版规范

本规范将竞品图库研究转化为可生产的原创 Listing 套图。它要求每张图是一份可交给生图、设计和质检人员执行的制作卡，而不是只写“场景图”或“结构图”。竞品只提供购买问题、证据方法和信息层级；不提供可复用的图片、文案、Logo、产品几何或场景布局。

## 1. 先定义整套视觉系统

在逐图制作卡之前，必须写出以下风格锚点：

| 字段 | 要求 |
|---|---|
| 受众与购买语境 | 买家正在决定什么；例如庭院休憩、遮蔽空间或外观匹配。不得将推测的用户需求写成产品性能。 |
| 视觉定位 | 如现代、克制、建筑感、温暖户外。避免“高级”这类不可验收词。 |
| 调色系统 | 3-5 个颜色角色：主色、背景色、强调色、正文色；记录色值或明确视觉描述。 |
| 字体与信息层级 | 标题、短副标题、标签、尺寸/免责声明的字号级别、字重、大小写、最大行数与安全边距。 |
| 版式系统 | 标题位置、信息区宽度、商品允许占画面比例、留白位置、细节框/引线/图标是否允许。 |
| 光影与修图 | 时间、色温、主光方向、阴影软硬、反射、对比度和质感等级。场景变化时可改变时间，但必须保持品牌调色与字版系统一致。 |
| 场景差异策略 | 为每张场景图指定不同地点、时段、镜头、活动或购买疑问；不得重复同一庭院、同一角度、同一家具组合。 |

主图是例外：不沿用附图的文字、图标、边框或装饰。背景遵从用户确认的任务与实际槽位；以下模板中的白底仅作白底上架槽位示例，不覆盖已确认的非白底要求。

## 2. 竞品洞察必须落到制作决策

对每个竞品图库先提取下列内容，再做自有图需：

| 竞品观察 | 必须转化为 | 禁止转化为 |
|---|---|---|
| 图序和购买问题 | 自有图组的决策顺序 | 机械复制张数或相同图序 |
| 商品占比、机位、留白 | 自有构图规则 | 复刻构图、景观或道具组合 |
| 文字密度、模块数量、信息层级 | 自有排版密度与阅读顺序 | 改写/复用竞品文案、图标、错误文字 |
| 用局部特写、使用状态或规范图证明卖点 | 自有 SKU 的证据方式 | 迁移竞品性能、尺寸、材料、结构或认证 |

报告必须有“竞品视觉语言 → 自有制作决策”表。没有这张表，不得声称竞品研究已经用于图需。

## 3. 每张最终图的强制制作卡

每一张图在 `01_plan/image-plan.md` 中必须包含以下字段。可以使用表格加分段，不能只用一行压缩掉细节。

```markdown
### 图 0X｜名称
- 图类型与唯一购买问题：
- 对应竞品洞察：仅写抽象证据方法；无可用洞察时写“无”。
- 本 SKU 事实与证据等级：A 级事实、待确认 B 级、禁止 C 级分别列出。
- 核心卖点与视觉证明：卖点必须有画面可见证据；写清是完整 SKU、局部特写、使用状态、规范示意还是成品信息模块。
- 场景与差异化：地点、时段/天气、活动、背景深度；并说明它与其他场景图在哪三项以上不同。
- 商品状态与机位：全景/中景/近景，正面/3/4/侧面/仰视，商品占比，必须可见与不可遮挡部件。
- 构图与视觉层级：主体位置、信息区、留白、细节模块数量、视觉阅读顺序、对齐网格和安全边距。
- 风格与真实感：色板、光向、色温、阴影、反射、材质外观、修图等级。
- 道具/人物边界：允许项、禁止项；明确哪些道具仅为尺度或氛围，绝不暗示包含。
- 成品文案：英文标题、英文副标题、可选标签和免责声明逐字列出，每一条写出事实来源；文案、已确认数字与引线直接纳入成品提示词。
- 排版规格：字体风格、字重、大小写、颜色、最大行数、位置、留白尺寸和移动端最小可读性。
- 生图提示词路由：主图 / 场景成品 / 功能成品 / 局部编辑；提示词文件路径。
- 输出与验收：画幅、像素、生成候选/版式规范/最终文件名；P0、P1 检查点；唯一返工方向。
```

## 4. 文案的事实边界

| 文案类型 | 允许条件 | 示例形式 |
|---|---|---|
| 描述性标题 | 直接描述 A 级可见结构或画面状态 | `DOUBLE-TIER ROOF DESIGN` |
| 氛围标题 | 不把情绪包装成性能或包含物 | `SET THE SCENE OUTDOORS` |
| 技术/性能标题 | B 级资料有可追溯来源后才允许 | 仅在确认后加入材料、等级或性能 |
| 尺寸/清单/认证 | 必须有原始数据或正式文件；直接生成并逐字核对 | 数字、单位、型号、包装件数 |

不得用抽象词暗示未经确认性能，例如将外观写成“weatherproof shelter”或将结构细节写成“built to withstand storms”。文案没有事实来源时，删去而不是弱化措辞。

## 5. Template 1：九图任务与差异要求

| 图号 | 必须完成的任务 | 场景/机位差异要求 | 文字与排版 |
|---|---|---|---|
| 01 | 主图，完整 SKU 识别 | 背景按确认槽位与用户要求，完整产品，稳定 3/4 或正面 | 无新增文字、无图标、无道具 |
| 02 | 场景价值 | 日间环境；全景或中广角 | 1 个情绪/用途标题 + 1 行副标题 |
| 03 | 第二生活方式 | 与 02 在地点、时段、机位、活动中至少三项不同 | 同系统，但不重复 02 文案 |
| 04 | 最大 A 级卖点 | 结构或使用状态的可读证据 | 中密度；标题和副标题随画面直接生成 |
| 05 | 关键工艺细节 | 微距/低机位/仰视等不同镜头 | 只标注已确认可见部件 |
| 06 | 第二 A 级功能 | 与 04 不同的部件或状态 | 中密度；不以大标题替代证据 |
| 07 | 补充差异点 | 与 05 不同的局部或视角 | 低至中密度；证据大于装饰 |
| 08 | 空间和使用语境 | 宽镜头，商品和周边尺度关系清楚 | 道具仅作环境/尺度，不暗示包含 |
| 09 | 尺寸、清单或产品概览 | 白底规范图；有真实数据时才放尺寸/清单 | 已确认数字和引线随画面直接生成并核对 |

## 6. 提示词与排版必须一体化

每张附图保存：

1. `02_prompts/0X_name.md`：按 `prompt-writing-standard.md` 的十段式编写完整英文成品提示词。SKU 锁定、场景、镜头、风格、光影、卖点证据、逐字文案、字体层级、模块坐标与引线规则均进入实际调用。
2. `04_layout/0X_name-layout.md`：同一版式的事实来源和验收清单；其内容不得成为提示词缺项的借口，不另设等待后期步骤。

直接生成画面、文案和排版完成的单张商品图。不得包含 `no-text base`、`add copy later`、`leave space for post-production` 等旧路线指令。主图仍无文字。对复杂信息先减少冗余文案、扩大模块；生成后逐字检查拼写、数字、单位、引线端点和手机缩略图可读性，不通过则局部修复。

## 7. 交付前审计

在最终图进入 `06_final/` 前，逐图检查：

- 是否能从图需找到竞品洞察、SKU 事实、文案来源和提示词文件？
- 场景图是否确实与其他场景图有三项以上差异？
- 标题是否只有一个购买问题，且画面有对应视觉证据？
- 商品结构、部件数量、连接关系和材料外观是否锁定？
- 文案、尺寸、性能、认证和清单是否均可追溯？
- 主图是否独立通过主图合规检查？
