# 套图与 A+ 历史案例复用

来源一：用户提供的 HOTEEL149 A+ 制作对话，包含执行记录、反馈与质检叙述，未提供可独立检查的原图及完整原始提示词。来源二：《SPC000327-沉浸式非对称V5-10张全套.zip》，含17份原始/修图提示词；ZIP尾部缺失，仅前三张PNG完整恢复并逐张查看800宽JPEG，原生均1254×1254，第四张未作为验收依据。不声称十张全部检查通过。

铁皮车棚套图实图：主图只展示产品；雨后归家附图用右侧主体、左侧暖光住宅、冷色环境与湿地反射构成动线，文字落在左下负空间；尺寸图改成高位斜视，长短边标注跟随轮廓。摄影本身提供设计，文字不承担全部丰富度。主图透明区域在预览显示黑色，不能据此声称白底已验收。

原始提示词分别写明参考角色、SKU锁定、具体机位、主体区域、纵深、光线、逐字文案和禁止项。其余提示词安排状态、材料、低位框架、门帘操作、另一种生活任务和错落步骤；修图还将难辨的安装全景改为有资料支持的搭接近景。这些是意图与迭代证据，不等于未见图片已经合格。

效果好的可复用因素：

1. 一套图有阅读节奏：英雄场景、尺寸、开合状态、材质证据、不同活动、搭建与收纳，各自解决购买问题。
2. 浅色标题、细金色图形与细节窗构成一致语言，完整环境提供空间纵深；不是每页相同卡片，也不是统一黄色底。
3. 先有认可版本，再基于实际成图局部编辑。人物尺度、网纱与杆件遮挡经历多轮明确校正，未修改图继续复用。
4. 手机从最新认可版独立重排：状态上下对照、步骤2×2、条件文字换行，保留完整产品与场景。
5. 换色以实际配色原件逐部件处理，材料窗、步骤和折叠清单一起检查，保护框架和配件颜色。

实施：

- 两个内置技能和本机对应技能增加 references/aplus-scene-editorial.md；商品工作流另加 listing-scene-editorial.md，通过 required_references 随入口加载、记录哈希。修复自动选择技能时默认分页截断必读正文的问题。商品工作流2.6.0，A+技能1.0.0。
- 视觉规范2.1.0增加“套图 / A+ 画册表达”：自适应、沉浸画册、可选浅色字与细金线。新网页方案默认沉浸画册，不强制白字金线。用户风格与配色优先。
- 图需在 objective/notes 和逐张 design 中写购买问题、证据、内容差异、手机重排及具体构图；冻结规范随可见提示词草稿保存，确认后不隐藏改写。
- 已有方案使用“采用新版设计规范”再保存，升级其已选内置技能，保留个人技能、技能范围与历史档案。选择套图/A+表达后重新策划和确认。新技能版本的发布不静默改写已有方案。
- Listing主图无新增文案、人物和非售卖道具，背景按确认要求；附图独立解决购买问题，保持实际图需画幅。A+可连续叙事，桌面默认1464×600，手机独立重排4:3。沉浸模式将主体占比、安全区、机位、动线、光照和落地关系写具体，不把镜头倾斜或同机位换背景当差异。
- 手机提示词补齐上下状态、细节与清单编排及600/375宽阅读要求。

没有照搬：固定十张、凉亭参数、特定配件数、所有产品用庭院/池畔场景、重复403重试、静默本地修补或换接口。以上方法不保证首次生成就达到案例经过多轮校正的水平。
