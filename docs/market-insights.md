# 市场洞察

入口：侧栏“市场研究 → 市场洞察”，路由 `#/market`。调研项目、来源快照和笔记默认团队可见；笔记仅作者和管理员可以修改。产品资料、个人模型密钥的隔离规则不变。

## 使用

1. 创建调研项目，明确选择站点。
2. 卖家精灵按关键词搜索类目，选择完整节点路径，按需获取概况、近24个月趋势、价格与评分分布、头部商品与品牌；每个模块单独提交1个业务查询。
3. 西柚支持关键词或单个ASIN定位类目，也支持空关键词发现方向；必须由用户选择自然月。返回1/3/5个类目，按实际主类目数每个5 Credits，最多5/15/25 Credits。复用搜索返回的销量趋势、新品份额及代表商品；不自动创建500 Credits研报资源。
4. 保存研究笔记，导出含来源与查询记录的JSON。

## 额度与执行

只由明确勾选费用确认的手动操作发起采集；无定时或页面访问触发采集。业务查询在持久化队列中串行处理，离开页面不会取消。浏览器每2.5秒只读取本地任务状态，不调用MCP。

相同服务商、工具和参数共用团队缓存；刷新需要显式勾选并重新提交。旧查询记录始终保留。复用结果显示本次消耗0，原始来源计费信息保留在快照中。卖家精灵实际chargedUnits/remainingUnits和西柚cost_credits分别展示，不合并不同额度单位；服务商未返回余额时显示“未返回”。

请求ID防止重复提交。数据库唯一active_key避免多账号并发提交同范围查询；其他项目订阅原任务结果。超时、解析失败或服务重启中断的已发出查询标记unknown，保留active_key，不自动重试。原发起人或管理员核对服务商状态后，才可解除待确认，显式刷新。普通明确失败保留错误，不自动重发。

## 配置与部署

管理员在受保护的 `.lan-runtime/deployment.env` 配置 `SELLERSPRITE_MCP_SECRET_KEY` 和 `XIYOU_MCP_TOKEN`。开发环境使用backend/.env。网站不读取Codex配置、不提供密钥读取接口，连接地址及允许工具均由后端固定。

部署前备份实际线上数据库并确认现有任务空闲，执行迁移`0027_market_insights`，重启API，构建前端。当前部署使用单个API进程管理市场查询队列。

## 数据口径

卖家精灵默认采用100样本档位，头部榜单取10项；近30天、归档自然月和历史序列分别标明。西柚搜索的概况属于所选自然月，销量历史属于完整可用范围。缺失值保留为空，不补0。类目商品数量、父体/代表ASIN及子体不混加，样本统计不标作官方全量；市场信号不能直接作为利润或销量承诺。

## 验证

后端使用模拟MCP覆盖幂等、团队复用、权限、来源校验、超时防重复计费及重启恢复；浏览器使用模拟API检查桌面与窄屏、切换项目、查询模块和保存笔记。验证不发起实际收费查询。
