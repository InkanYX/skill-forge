# 产品市场调研与卖点优先级

在产品资料页保存调研范围，再点击“调研并提炼产品卖点”。调研资料与用户上传资料共同用于分析，确认后的结构化卖点随产品分析快照进入各套图片策划。

## 统一配置

管理员在后端环境变量或后端 `.env` 中设置 `SELLERSPRITE_MCP_SECRET_KEY`。局域网部署使用 `SKILL_FORGE_DEPLOYMENT_ENV` 指定的受保护配置文件。网页仅显示配置状态，不提供密钥输入或读取接口；个人文本/图片模型仍使用各自账号的配置。

服务地址固定为 `https://mcp.sellersprite.com/v2/mcp`，Streamable HTTP 传输，通过 `secret-key` 请求头鉴权。只开放商品详情、内容资产、标准评论三个读取工具，不接受用户指定的任意服务地址或工具。

## 范围与额度

第一版支持指定自家/竞品 ASIN，共计最多 5 个，最多 200 条评论。每个商品对 1–3 星、4–5 星分层取样，默认各半；最多一次批量商品信息和每商品三次数据查询。评论为父体维度，样本比例不代表市场比例。实际扣费以卖家精灵账号规则为准。

相同产品及调研范围复用缓存。成功步骤保留；非不确定错误最多在后续人工提交时补试一次。发送查询前记录待确认状态，超时、中断、结果过大等不确定结果不自动重发。显式勾选刷新会重新查询并可能重复扣费；旧快照归档保留。鉴权拒绝停止剩余查询。

调研失败或无评论时可继续本地资料分析，保留明确警告，不生成虚构的评论证据。文本模型失败不删除已取得的调研资料。

## 证据与确认

每条卖点记录稳定 ID、优先级、买家需求、排序理由、产品依据、实际资料 ID、实际评论 ID、展示建议及表达限制。后台剔除不存在的引用，缺少当前产品依据的候选归为 VERIFY。排序、级别与文字摘要可由用户调整并确认。评论字段不保留买家姓名、邮箱或头像。

确认分析后的策划继承完整分析快照；新的调研不会改写旧策划。卖点及证据随文档进入团队共享和完整案例。模型编写图需时只接收已确认结论，不反复注入完整评论集合。P1 优先覆盖，VERIFY 不得作为已验证优势，Listing 主图仍不新增广告文案。

不新增数据库表或迁移；调研设置与当前报告存于产品记录，原始步骤及归档存于该产品的 `market-research/` 目录。

## 验证

后端回归使用模拟 MCP 和模型，覆盖请求头鉴权、SSE、工具白名单、错误脱敏、缓存、显式刷新、去重、超时防重发、权限拒绝、证据降级和账号隔离。浏览器验证拦截全部 API，不消耗真实查询额度。
